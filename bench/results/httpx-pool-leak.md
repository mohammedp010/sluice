# httpx connection-pool leak under cancellation

Generated by `bench/httpx_pool_leak.py`: httpx 0.28.1, httpcore 1.0.9, anyio 4.15.1. Each round sends 5 x 300 requests with limits from 1 to 60 ms at a 50 ms upstream. Pool limit: 100.

| timeouts | round | pool entries stuck in CONNECTING |
|---|---|---|
| cancel | 1 | 22 |
| cancel | 2 | 39 |
| cancel | 3 | 58 |
| cancel | 4 | 74 |
| cancel | 5 | 91 |
| cancel | 6 | 100 |
| cancel | then one normal request | **PoolTimeout** after 5.0s |
| native | 1 | 0 |
| native | 2 | 0 |
| native | 3 | 0 |
| native | 4 | 0 |
| native | 5 | 0 |
| native | 6 | 0 |
| native | then one normal request | 200 in 0.06s |

Cancelling the task (`asyncio.timeout`) mid-connect strands pool entries for good; httpx's own timeouts clean up. See ADR 0007 for what this did to Sluice under load.
